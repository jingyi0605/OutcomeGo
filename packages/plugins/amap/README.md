# 高德地图

这是一个默认不启用的高德地图插件。启用前，用户必须阅读并同意高德地图 Web 服务 API 使用条款，并提供 Web 服务类型的 API Key。

## 连接

1. 在高德开放平台创建应用。
2. 添加 Key 时将服务平台选择为 **Web 服务**。
3. 阅读[高德地图 Web 服务 API 使用条款](https://lbs.amap.com/pages/law-web-service/)并勾选同意。
4. 在插件设置中保存 Key，然后连接。

插件只使用用户账户设置中的 Key，不把 Key 写入插件文件或工具结果。

## 工具

| 工具 | API | 返回内容 |
| --- | --- | --- |
| `SearchPlaces` | Amap 地点文本搜索 | 地点名称、地址、坐标、分类和高德地图链接 |
| `SearchNearbyPlaces` | Amap 周边搜索 | 半径内地点、距离、地址、电话、营业时间和高德地图链接 |
| `RoutePlaces` | Amap 驾车、步行和骑行路径规划 | 路线几何、距离、耗时、分段和转向说明 |

所有工具都是只读操作。

## 坐标处理

插件对外使用应用的标准 WGS-84 坐标。调用高德 API 前会转换为 GCJ-02；收到高德地点或路线后会转换回 WGS-84，再交给地图展示层。

搜索一个地标附近的地点时，先用 `SearchPlaces` 获取高德 POI 坐标，再把该坐标传给 `SearchNearbyPlaces`。不要用普通地理编码结果替代 POI 坐标。

## 条款和数据

地点名称、搜索区域和路线坐标会发送到高德 Web Service API。高德服务的配额、授权范围、调用限制和商业使用条件以高德当前控制台和条款为准。
