# WeChat plugin artwork

The plugin icon uses WeChat's official two-bubble vector mark from Tencent's CDN (`https://res.wx.qq.com/a/wx_fed/assets/res/MjliNWVm.svg`) in white (`#FFFFFF`) centered on WeChat's official brand green (`#07C160`) rounded tile (`icon.svg`; the 192×192 RGBA `icon.png` is rasterized from `icon.svg`). WeChat and WeChat ClawBot are trademarks of Tencent; the asset is included only to identify the provider in the plugin catalog.
