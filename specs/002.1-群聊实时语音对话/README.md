# 规格文档：群聊实时语音对话

规格编号：`002.1`

状态：草案

日期：2026 年 11 月 10 日。

本 Spec 在 `002-实时语音对话` 的单 Bot 私聊能力之上，增加群聊频道中的实时语音会话。它定义参与 Bot 选择、群聊语音唤醒、Bot 静默判断、顺序说话、循环防护、数据持久化、客户端行为和验收规则。

本 Spec 与 `specs/002-实时语音对话/` 的关系：

- Spec 002 负责单 Bot 私聊实时语音、媒体链路、Provider、WebSocket、VAD、STT、TTS 和直接会话生命周期。
- Spec 002.1 复用 Spec 002 的媒体与连接能力，将消息接收和回复协调扩展到群聊频道。
- Spec 002.1 不改变普通文本群聊的响应规则，也不改变现有语音笔记行为。

本 Spec 使用 `specs/000-Spec规范/Spec模板/` 的目录和文档结构：

- `requirements.md`：需求、用户故事、范围、验收标准和非功能要求。
- `design.md`：架构、接口、数据模型、状态、错误处理、正确性属性和验证映射。
- `tasks.md`：分阶段可执行任务、依赖、文件范围、完成条件和验证方式。
- `docs/`：必要的补充验收、协议或迁移材料。

第一版的核心原则是：被解析出的 Bot 获得一次“判断是否相关”的机会，但不被强制要求发言。Bot 可以静默完成，系统不生成填充性消息、字幕或音频。
