# 规格文档：群聊实时语音对话

规格编号：`002.1`

状态：草案

日期：2026 年 11 月 10 日。

本 Spec 在 `002-实时语音对话` 的单 Bot 私聊能力之上，增加群聊中的实时语音。

做法：语音转写作为普通群聊用户消息进入现有群聊流程，Bot 的群聊答复在投递完成后按顺序朗读。点名、串行投递、静默完成、幂等、淘汰旧回合和消息上限都复用现有群聊机制。新增内容只有语音点名解析、语音回合不追问、投递完成后朗读，以及数据库中的 `VoiceSession.participantBotIds` 一列。

与 Spec 002 的关系：

- Spec 002 负责媒体链路、Provider、WebSocket、VAD、STT、TTS 和会话生命周期。
- Spec 002.1 复用这些能力，只扩展会话创建、转写接收和答复朗读。
- 普通文本群聊和直接语音的行为不变。
