# Spec 012.1：本地服务托盘管理与引擎配置

状态：Draft

本 Spec 是 [Spec 012：桌面端一键本地部署](../012-桌面端一键本地部署/README.md) 的子规格，聚焦**本地自托管部署完成后的日常运维与配置管理**。

背景：Spec 012 解决了 Windows 与 macOS 桌面端“一键部署本地服务端”和“基础托盘常驻”的问题，但用户在实际本地托管使用中仍面临明显短板：
- 任务栏托盘菜单仅有“打开 / 启动或停止 / 退出”，且存在状态刷新滞后（服务已运行仍显示“正在启动本地服务”），缺少“服务管理”入口与快捷运维操作；
- 无法在桌面端直观查看各 Docker 容器（`server`、`worker`、`computer`、`postgres`、`computer-memory-init`）的运行状态、资源占用和日志，也无法重启单个异常容器；
- 开机自启动策略固化在启停命令中，缺少“本地服务开机自启”与“桌面端登录自启”的独立可视化开关，macOS 托管引擎也尚未提供登录自启；
- 资源配置入口藏得较深且无法回显当前值，未覆盖 CPU 限额、Worker 并发及托管引擎（Lima VM / WSL2）资源概览；
- 国内或企业代理环境下，缺少面向本地服务端容器出网（模型 API、网页搜索、插件）及托管 Docker 引擎拉取镜像的统一代理服务器配置。

## 一页摘要

- **托盘菜单增强与状态同步修复**：修复本地模式下的托盘状态延迟与部署完成未刷新的问题；右键菜单增加“服务管理…”直达入口、“重启本地服务”、“开机自动启动本地服务”快捷开关与“打开日志目录”。
- **容器视图与单容器运维**：在「设置 → 服务器 → 本地服务管理」中展示全部服务容器的运行/健康状态、实时 CPU 与内存占用，支持单容器重启与日志查看/复制（自动脱敏）。
- **开机自启动解耦**：独立控制“本地服务开机自启”（Windows 复用免 UAC 计划任务 `OutcomeGo-ManagedEngine`，macOS 新增用户级 LaunchAgent，外部引擎只读说明）与“登录时启动 OutcomeGo”（Electron `setLoginItemSettings`，支持后台静默启动）。
- **性能与资源配置**：回显当前生效配置，支持预设档位与自定义调整 `computer` 内存/CPU、`desktop` 内存、`worker` 并发，以及托管引擎（macOS Lima VM 直接编辑，Windows WSL2 安全读取与可选写入 `.wslconfig`）。
- **代理服务器配置**：提供直连 / 跟随系统代理 / 手动代理（HTTP·HTTPS·SOCKS5 + `NO_PROXY`）配置与一键测通，统一作用于容器出网（`.env` + `compose.yaml`）、托管 Docker 镜像拉取（daemon drop-in）及 CLI 资产下载；本地回环代理自动转换容器可达地址。
- **架构边界不变**：所有对安装目录、`.env`、Docker Compose 与托管引擎的读写继续由 CLI 统一承接，桌面端通过结构化 JSON 与 IPC 调用，不破坏 Spec 012 与远程/Linux 部署兼容性。
