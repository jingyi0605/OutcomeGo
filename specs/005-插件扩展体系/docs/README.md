# Spec 005 补充文档

本目录保存插件扩展体系的能力矩阵、跨插件生命周期、来源完整性、兼容性和最终验收记录。

建议补充以下文档：

- `20261112-插件能力与生命周期矩阵.md`：记录现有插件类型、配置存储、worker scope、运行位置和生命周期。
- `20261112-插件扩展验收记录.md`：记录父级安装、connector 账号、更新回滚、浏览器凭据、恶意 provider 内容、卸载清理和 1Password 回归。
- `20261112-插件发布与回滚检查.md`：记录 package revision、来源完整性、构建、测试、兼容性和回滚证据。

补充文档必须使用中文内容和带日期的中文文件名，不得写入真实 API Key、密码、OAuth token、session key、完整密码或 TOTP。
