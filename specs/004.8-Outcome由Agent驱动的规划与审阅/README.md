# Spec 004.8 - Outcome 由 Agent 驱动的规划与审阅

状态：Draft

## 一句话

目标管理里所有需要理解语言、判断意图的环节（新建、规划、修改、拒绝、取消、追问），都交给机器人在 PI Agent 回合里完成；程序只负责权限、幂等、状态派生和调度。用户对目标说的每一句话原样交给该目标的专属线程，由机器人自己决定怎么办。成果简报、成果摘要、验收预审是后台展示内容，仍由一次性 LLM 在后台生成，不在本 Spec 范围。

## 为什么要做

004.2 把规划做成"服务端拼提示词 → 一次性调用模型 → 解析 JSON → 固定向导"。用户在待批准的目标上写"取消目标"，系统仍然生成了一份"取消目标的规划"。固定流程没有判断力，也让 Agent 失去了自由度。

## 文档

- `requirements.md`：需求与验收标准
- `design.md`：架构、数据模型、工具与状态派生
- `tasks.md`：任务拆解、验证方式与回写状态
- `docs/`：补充材料（迁移说明等，按需添加）
