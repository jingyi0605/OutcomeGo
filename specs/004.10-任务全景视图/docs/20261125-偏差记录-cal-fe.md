# 会话 F：日历界面偏差记录

## cal-fe-1：8.2 与 8.4 采用 IN_REVIEW

8.2 的订阅管理界面和 8.4 的外部日历叠加已完成本地实现。验证范围限于离线测试、桌面端类型检查和服务端类型检查。

真实日历应用订阅、Google OAuth、远端 computer 调用和授权撤销没有执行。8.3 的可行性结论已证明宿主调用路径可行，但第三方账号验收仍由所有者另行批准。

## cal-fe-2：外部日历选择保存在桌面端本地

当前仓库没有为外部日历选择新增数据库设置列。账号 ID、日历 ID 和只显示忙选项保存在桌面端本地存储，服务端每次按选择调用只读工具，不缓存事件，不向 bot 暴露数据。若后续要求跨设备同步选择，需要单独增加设置持久化契约。
