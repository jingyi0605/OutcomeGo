## 安装检查

在当前 macOS ARM64 工作区使用官方 `v1.0.68` Release 资产完成安装。安装器将二进制放入版本专属目录，版本输出为：

```text
dws version v1.0.68 (ba02fc6cdbdb3543d21d0cdb70f027bf0d142692, 2026-11-11T08:18:05Z)
```

安装器和包装脚本通过了 Bash 语法检查。离线专项测试覆盖：

- 缺少 CLI 时 `--check` 不会下载；匹配版本会复用；
- 已有未知版本时拒绝覆盖并保留原文件；
- 不支持的平台在下载前失败；
- 下载源固定到官方 Release，摘要错误会停止安装并清理暂存目录；
- 参数按字面传递，显式的配置目录、凭据目录和 profile 会保留；
- `dws-status.sh` 只读转发当前 Computer 的状态；
- `dws-logout.sh` 保留 profile 选择器并强制通过 DWS logout；
- `dws-auth-export.sh` 只允许把 bundle 写入 workspace；
- `dws-auth-import.sh` 只接受 workspace 内的普通文件，验证 `authenticated: true` 后删除 bundle，失败时保留；
- 插件导出回读、许可证/NOTICE 摘要、技能链接和敏感文件排除检查。
