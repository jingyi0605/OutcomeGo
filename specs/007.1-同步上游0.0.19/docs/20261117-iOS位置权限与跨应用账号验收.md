# iOS 位置权限与跨应用账号隔离

来源：`aa229f8f9`、`2ad629a66`、`1320e7816`、`a77708d95`、`aa7e2ec5c` 的 iOS 能力，按 Phase 2 的 OutcomeGo 契约重新实现；不复制上游裸 DeviceLocation 请求或全局 shareLocation 偏好。

## 本地实现与兼容

- `SendInput.location` 是可选的 `{fix, sharingRevision}`，fix 的 latitude/longitude/accuracyMeters/capturedAt/device 对齐现有 TypeScript；身份来自固定 API/认证会话，不放 userId 到位置字段。位置仅在实际发送前准备，不写入持久 outbox。
- `/api/v0/location` GET/DELETE 与 `/api/v0/location/sharing` PUT 使用现有服务端协议，启用必须携带 expectedRevision。已关闭/换账号等待中的位置请求取消；提交期间有 generation watchdog，服务端 CAS tombstone 负责最后的事务隔离。已被服务器接受的消息不能靠客户端取消撤销，继续按原 nonce 核实，不能自动重发。
- 服务端 `OUTCOMEGO_LOCATION_ENABLED` 仍仅 `1` 开启，默认关闭。返回 404 时不显示 iOS 开关；本地同意按 server/user 分区，默认 false。只请求 When In Use，不增加 Always 或 location 后台模式。Shortcuts 仅复用已明确授予的同意，不主动弹新权限；Share Extension 不附带位置、不申请 GPS 权限。
- 关闭先取消本地工作再 DELETE。离线清除保存 clearPending 标记，回前台/打开设置时用原账号重新核实、清除；离线时不能声称服务器旧位置已删除。重新启用前先完成待清除操作。
- 本地 SessionRecord 增加可选 ownershipID，新建连接生成 UUID，旧 Keychain 记录缺字段仍可解码；显示名刷新保留该字段。原 token/server/user 校验保留，额外阻断 A→B→A 复用同样凭据时的迟到操作。
- Shortcuts、Share Extension、Spotlight 写入在网络边界核对该会话。语音闭包另外检查 API.resourceGeneration，防止旧对话转写回到新连接。Share Extension 换账号后清空旧上传/目标缓存，失败保留本地文件供用户处理。
- Sources、Core、ShareExtension 和 OutcomeGoApp 的现有路径沿用；Info.plist 只增 When-In-Use 权限说明，没有更改 bundle、签名、版本、更新通道或 artwork。

新增 ProtocolTests、SessionRecordTests 和 LocationSharingTests 源码；已有断言不删改。swift-format 解析只证明语法可解析，不证明类型、actor isolation、AppIntents/Extension API 可用性。

编译、`xcodebuild`、`swift test`、CoreTests/SystemTests/UITests：**not executed, reason: missing full Xcode**。

## 必须真机验收的 checklist

- [ ] 测试服务器保持 flag 关闭：打开设置、冷启动 Shortcuts/Share Sheet；预期不显示位置开关、不请求定位、不发送 location 字段。
- [ ] 在隔离测试服务器开启 flag，首次启用开关：分别拒绝、允许 When In Use、选择模糊位置；预期拒绝后保持关闭，允许后发送 revision envelope，精度/时间与 GetUserLocation 相符，不要求 Always 权限。
- [ ] 将 GPS fix 延迟，在等待中关闭再开启共享、撤销系统权限、切账号/服务器，含 A→B→A；预期旧请求不发到新会话，不带过期修订发送，不出现自动重发。对已进入 POST 的情况检查服务器 nonce 状态。
- [ ] 关闭共享时断网：预期本机立刻停止准备位置，服务器清除显示为未核实；联网回前台后 DELETE 成功且旧 fix 不再可读；失败期间不暗中重新开启。
- [ ] 给 A 账号配置 Shortcuts 的发送目标，操作延迟期间切至 B/重新连接 A；预期旧动作拒绝，不将 A 的附件/目标放入 B。验证未解锁、首次授权、Keychain 不可读和 App 冷启动。
- [ ] 在其他 App 的 Share Sheet 选择 PDF，上传中切换 OutcomeGo 账号后返回；预期拒绝旧提交，重载后必须重新确认目标，不复用另一账号的 uploaded asset；成功/失败/取消均检查源文件处理。
- [ ] 后台语音转写期间切账号并切回同一账号，检查 token 相同的 auth-disabled 测试部署；预期 API generation 和本地 session epoch 均使旧结果失效。

回滚：整体 revert 本能力组（App/Core/ShareExtension 的同组变更一起回滚），旧版本忽略可选本地 ownershipID；无需更改 TypeScript 契约/数据库。回滚前关闭位置共享并核实服务端清除；不要删除 outbox 或跨账号合并日志。
