## 必须真机验收的 checklist

- [ ] 在可分栏 iPad/宽屏布局进入会话并隐藏列表，从屏幕 leading 侧 3/22/32pt 处拖入；长拖/快松应显示会话列表，短拖/反向松手应取消，当前会话与滚动位置保持。
- [ ] 反复在展开/收回过渡期间再次拖动、旋转、改变窗口大小，检查不留遮罩、不重复列表、不污染 viewport 未读统计。
- [ ] 详情 push、线程、地图/照片全屏、sheet 打开时进行同样手势；预期分别保留系统返回/媒体手势，不能从后层误拉列表。
- [ ] 在消息内容从非边缘位置进行横向回复、上下滚动、键盘显示/隐藏；预期不抢手势、不误触回复、不丢焦点。
- [ ] RTL、Reduce Motion、VoiceOver、iPad 浮动窗口/分屏逐项验证；RTL 侧别正确，Reduce Motion 不依赖动画完成才可操作，浮动窗口非屏幕边缘不误触。
