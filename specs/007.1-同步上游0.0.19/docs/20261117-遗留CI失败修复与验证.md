## 实现与兼容

- 更新前拒绝 `stateRemovalPending`；更新/回滚共享同一套校验。
- connection 的 generation 在事务认领时只增加一次；后续更新不重复增加。已删除、已移除、已重新配置或已变更的快照会导致整个事务回滚。
- 安装快照还必须保持 `installed` 状态；兼容更新不清除私有 credentials，原有 connector/account identity 不变。
- 现有三条失败断言原样保留；无新增跳过、retry wrapper、宽松断言、timeout 或 CI retry 调整。
- 全仓 workflow/scripts 检索未再发现可执行的旧 scope filter；历史审计 fixture 和命名转换脚本的旧 scope 作为证据保留。

## 风险与回滚

- 并发账户状态变更会主动拒绝包更新，调用方刷新后需重新审核更新；不会覆盖账户移除 gate。
- 从 persistentState=true 变为 false 或删除 connector 的包，需要先移除账户并卸载旧包，防止留下不可管理的磁盘状态。
- 无数据库迁移、UI、iOS/Android、版本或发布配置变更。回滚本 PR 的提交可恢复原实现，但会重新暴露状态丢失风险。
