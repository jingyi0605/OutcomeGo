## 3. 候选发布说明草案

以下供后续正式发布整理，尚未通过全量检查或原生设备验收，不能直接宣称所有平台已发布。

### 位置基础设施

- 增加按认证账户隔离的 UserLocation、共享 revision、位置 API 和 Computer `GetUserLocation` 工具，位置字段保持可选，不要求旧客户端升级。
- opt-out、权限撤销和账号切换取消旧本地工作，服务端 tombstone 拒绝迟到修订；已被接受的消息仍须按既有 nonce 核实，不自动重发。
- `OUTCOMEGO_LOCATION_ENABLED` 默认关闭，只有 `1` 开启；启用前必须先验证数据库部署。新表为 `outcomego_user_location`，复制库升级、读取和回退/前向修复步骤见[阶段 2 手册](20261117-位置基础设施与数据库验收.md)。
- 多用户部署的工具读取限制、离线位置清除延迟和非实时位置含义仍按阶段 2/5 记录，不作地址精度或即时删除承诺。

### 执行可靠性

- 指定 routine/follow-up 自动 wake 最多四次 attempt（包含初次），重试间隔为 30 秒、2 分钟、5 分钟，使用持久 attempt 与 lease owner fencing。
- 旧 worker 的迟到结果不能覆盖后继 attempt；显式 Stop 在延迟完成下仍有效，已投影完成的请求可继续幂等结算。
- 启动及周期恢复失去有效 lease/通知的 wake，保留 Bot main session、多实例 routing 及本地 external message recovery 的既有语义；不重放已行动或不确定的外部发送。

### Desktop 投递

- 草稿编辑、发送/丢弃意图与回执跨重连/重启持久化；失败保留正文、引用和附件描述。不确定结果先只读核实目标，不自动重复提交。
- Messages PDF 交接使用私有 durable staging，保留系统异步消费所需字节；仍需真实 Mac/测试收件人的端到端验收。
- 通知焦点/已读投影和服务器 read 范围保持一致，消息列表测量保留阅读锚点。

### iOS 原生源码（尚待设备验收）

- 已提交录音的转写和 outbox 获得有限后台时间，离开对话/切 App 后可在系统额度内继续；不是无限后台执行或强杀后恢复保证。
- 跨 App 发送叠加本地账号 epoch；位置权限按账户隔离，首次授权只能由明确前台操作触发。
- 修复全屏地图照片 pin 的独立 host 环境，增加 PDF 持久交接、边缘拖出列表和上方行测量补偿。
- 具体操作及预期结果沿用[阶段 5 的 Unverified items and acceptance steps](20261117-iOS原生增量与静态验收.md#unverified-items-and-acceptance-steps)及六份分组 checklist。
- **not executed, reason: missing full Xcode**：iOS 编译、Swift/SDK/actor isolation 类型检查、`swift test`、SystemTests、UITests、真机/TestFlight、Shortcuts 权限、地图/附件沙箱、通知和边缘手势。

6. **工作边界**：本阶段仅 push 新的 release-metadata 分支并开 draft PR，等待 Jackson 审查；不再次写 OutcomeGo、不创建 tag/Release、不改生产环境。阶段 6 永久跳过，不在本任务后续计划中。
