# iOS 后台语音与发送：实现及真机验收

来源：`52962bac8`，仅取后台时间管理、语音和发送生命周期；不取该提交对旧 UI 测试预期的修订。

- `BackgroundTime` 对用户已经提交的转写和 outbox 发送申请有限后台时间；完成、取消、账号退出及系统到期时释放，同一释放函数可重复调用。
- 已离开对话的转写仍由原有 `VoiceMemoSessions` 持有；录音本身不因此获得后台常驻权限。
- 沿用本地持久 outbox、nonce 核实和显式重试规则，不将未确认发送自动重发。iOS 给出的时间有限，不能保证超长转写一定在后台完成。
- 新增/补充 SystemTests 源码用于后续执行，原有断言保留，没有新增 skip 或改低超时阈值。

静态验证：对本组六个 Swift 文件使用 CLT 的 `swift-format format <file>`，输出丢弃，退出 0。它只验证 SwiftSyntax 能解析源码，不验证 SDK、类型、并发隔离或链接。

编译、`xcodebuild`、`swift test`、SystemTests、UITests：**not executed, reason: missing full Xcode**。

## 必须真机验收的 checklist

- [ ] 使用 TestFlight/真机连接已配置语音服务的测试服务器，录制语音并发送，在转写期间退回会话列表再进入另一对话；预期只向原对话发送一次，返回原对话可见进度或最终消息。
- [ ] 发送后立即切换至另一 App/锁屏，在系统后台额度内等待后返回；预期成功结果进入原 outbox/会话，后台任务及时结束。不能把此项当作无限后台执行承诺。
- [ ] 模拟慢转写、网络中断及系统后台时间到期；预期没有无限持有后台任务，失败时保留可重试录音/持久草稿，恢复后先核实不确定发送，不出现重复消息。
- [ ] 转写期间取消、退出账号或切换服务器；预期立即释放本地后台租约，旧转写不能发到新账号。验证前台及已离开对话的 controller 两条路径。
- [ ] 转写完成时 App 仍在后台，点击相应通知；预期定位到正确对话，原生通知与服务器已读最终一致。此项验证现有通知链路，未导入上游通知测试的等待调整。

回滚：只 revert 本能力提交；保留已有 outbox 和附件数据。回滚会恢复原先可能在 App 切换后暂停的行为，不执行数据库迁移。
