## 实现

- 恢复 `recoverMemoryReviews()`、`reviewMemoryRun(runId)`、持久 `recordMemoryFromRun(runId)`；启动时扫描，之后每五秒扫描，关闭时清理定时器并等待本地审阅完成。
- 每轮最多保留 32 个本地后台审阅；每 bot 只选择最旧的合格 Run，使用完成时间与 UUID 稳定排序、bot 游标轮转、本地 Run 去重。恢复扫描不等待模型推理完成。
- 只有普通 user/group、非 reaction、非 subagent 执行提交新意图。结算事务先取得既有 agent lifecycle gate，再同 inbox 结算一起保存 pending 与 agent/shared memory revision；随后发布群聊缓冲回复，再审阅。
- 历史 Outcome、Routine、bootstrap、reaction、subagent 的记忆审阅意图只确认跳过；不把其业务内容学习到主聊天记忆，不重开任务、不调用 Computer 执行回放。
- 使用当前 `outcomego_run`、`outcomego_inbox_event` 物理表映射，复用 `AgentDataStore` 现有持久 lease、数据库时钟、owner 校验、取消/删除 fencing、revision 与原子确认。保留当前 voice narration 过滤，补回群聊触发用户消息和中断后缓冲回复发布恢复。
- 四个实际集成 fixture 改为当前 `OUTCOMEGO_*` 配置键：multiworker、inference-outage、journey、lifecycle-reliability。未修改原始重启测试、子进程 hook、超时、sleep、真实 TTL 或幂等断言。
- 新增两项聚焦回归：历史 automation/reaction 意图不会污染普通聊天记忆；持久恢复保留可见答案但排除 voice narration。

未编辑 claim、fail、OutcomeService、集成入口或其他并行所有者的代码块。与 runtime、Human/Stop 所有者已协调生命周期锁和文件区域。
