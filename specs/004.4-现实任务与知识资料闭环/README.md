## 可实施边界

本阶段把人工执行当作一种一等 WorkItem，但不把它伪装成 Agent Run。系统负责生成资料引用、动作卡、输入和验收条件；用户或现场人员负责执行并提交回执。

第一版 KnowledgeProvider 使用可替换的只读适配器。实现者必须先接入一个当前仓库可读的资料来源（项目文件、已保存文件或明确的 fixture），再预留 X-File 等未来 provider，不得为了接口完整性引入第二套知识库。

现实任务的完成证据必须来自人工回执、外部记录引用或既定检查结果。AI 生成的步骤本身只能作为建议，不得作为执行事实。
