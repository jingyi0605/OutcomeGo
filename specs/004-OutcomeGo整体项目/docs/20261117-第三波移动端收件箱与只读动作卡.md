## 3. 实现行为与合同

### 3.1 Inbox 与旧服务器

四类为 `decision_pending`、`acceptance_pending`、`human_action_pending`、`completed`。使用直接返回的 `OutcomeInboxPage {items,nextCursor}`，查询带 `status=all&limit=30`；分类和 opaque cursor 通过已有编码机制传递。

卡片显示标题及“已完成 / 当前问题 / 下一步”。待验收和待人工处理显示 Desktop 引导；未知分类显示通用更新文案。分页失败保留已有行和 cursor，重试失败页；成功合并时按 ID 去重，空 cursor 结束分页。网络错误保留本次页面已经成功读取的内容并提示可能过期，没有新增持久化的私密卡片缓存。

沿用第一波按认证 gateway/session 或 API generation 重置的 capability 探测；`GET /api/v0/outcomes` 集合 404 隐藏入口。Inbox 集合 404 显示当前服务器不支持 Inbox，仍保留 `All outcomes` 兼容入口。单条 Decision/Outcome 404 是读取失败，不误判整个服务不支持。

### 3.2 Decision

读取 `GET /api/v0/decisions/:id`，提交唯一移动端 Outcome 写接口：

```text
POST /api/v0/decisions/:id/resolve
{ optionId OR customText, expectedContractRevision, clientRequestId }
```

选项无默认选中；支持后果、推荐依据、自定义文字和展开详情。未知或终态 Decision 不能提交。草稿最多 4,000 个 UTF-16 单元，与服务器/Android 长度规则一致。

每次尝试固定完整请求体与 `clientRequestId`；网络不确定错误重试原尝试，用户修改选择或文字才创建新尝试。提交中禁止重复操作。409 后重新读取当前 Decision，保留选择/文字；选项被移除时提示重新选择。410 显示过期并刷新。成功后显示 resume 状态并刷新当前卡片。刷新失败重试 GET，提交失败才重试原 POST，不把读取错误变成新提交。

不提交 `actorRef`、批准人、验收人或最终状态，不在移动端实现批准新修订。

### 3.3 人工动作和回执只读

使用 `GET /api/v0/work-items/:id`。显示目的、前置条件、步骤、输入要求、证据要求、服务端保存的 Desktop 进度、状态和修订。资料引用由用户展开，显示来源、版本、权限摘要、过期提示和可选摘录，不自动插入正文。

兼容可选 `receipts`，倒序显示 sequence、状态、提交时间、comment/text、审核意见和缺失要求。只读 DTO 忽略未使用的 receipt payload 字段，保留未知状态容忍能力。

没有 start、pause、receipt upload/submit 或 review 写入口；统一提示“请在 Desktop 完成”。读取人工动作详情不调用状态修改 API。

### 3.4 通知、登录和前台入口

识别 schemaVersion 1、kind `outcome` 和四种既定类型：

```text
outcome.decision.required
outcome.review.required
outcome.human_action.required
outcome.accepted
```

验证 UUID、类型、deepLink 与目标 ID 一致；未知版本/类型不当作可打开 Outcome 通知。保留旧 message/reaction/badge-sync 解析。Outcome 不进入聊天已读抑制，也不因为对应 Bot 的聊天在前台而被吞掉。

Android 在真实 `AndroidPlatformRuntime` Intent 入口处理 canonical Outcome URI；PendingIntent 和待导航状态只携带目标 ID。未登录先认证，成功后恢复；旧 session/gateway 的 401 不得注销新 session。

iOS 启动恢复、URL scheme、后台恢复中的 notification resume 和通知点击进入同一个 `pendingDeepLink` 路径。APNs 待处理内容仅保留 ID 与 notification scope，认证后再次核对账号范围。API generation 防止旧账号响应写回当前页面。重复显式点击同一目标可重开页面；不缓存通知正文用于渲染业务卡片。
