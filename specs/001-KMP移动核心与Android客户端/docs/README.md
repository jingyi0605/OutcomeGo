# Supporting Documents

The `docs/` directory stores material directly related to this Spec.

Suggested documents:

- `api.md`: mobile endpoint and payload inventory
- `integration.md`: KMP-to-iOS and KMP-to-Android integration notes
- `acceptance-checklist.md`: Android and iOS acceptance checklist
- `acceptance-result.md`: recorded validation results
- `migration.md`: iOS migration and rollback notes

Add a document only when it contains information that would make the main Spec
harder to read or that needs to be maintained independently.
